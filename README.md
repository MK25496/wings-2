# wings-2

## Python Learning Roadmap

This repository now contains an actionable roadmap to help you learn Python step by step.

### 1) Define your goal first

Pick one primary goal:
- Automation
- Web apps
- Data science
- Scripting
- Interview prep

Write your goal in one sentence and keep it visible while studying.

### 2) Learn core Python basics

Work through these topics in order:
1. Variables and data types
2. Conditionals (`if/elif/else`)
3. Loops (`for/while`)
4. Functions
5. Lists, dictionaries, and sets
6. File handling (read/write text files)

### 3) Practice daily (30–60 minutes)

Use this daily split:
- 10 min: review yesterday’s topic
- 20–40 min: solve small exercises
- 10 min: summarize what you learned

### 4) Build 2–3 beginner projects

Start with:
- Calculator
- To-do CLI app
- File organizer

Build one project at a time and finish each before starting the next.

### 5) Learn debugging and error handling early

Practice:
- Reading tracebacks
- Using `print()` and breakpoints to inspect values
- Handling exceptions with `try/except`

### 6) Pick a track after basics

Choose one path:
- **Web:** Flask or Django
- **Data:** NumPy, Pandas, Matplotlib
- **Automation:** scripts + APIs

### 7) Start using Git/GitHub

For every exercise/project:
- Initialize a repo
- Commit progress regularly
- Push to GitHub

### 8) Solve coding problems weekly

Do 3–5 problems every week focused on:
- Loops and conditions
- Strings and lists
- Dictionaries
- Basic algorithms

### 9) Review and refactor old projects

Every 2 weeks:
- Rename unclear variables
- Break large functions into smaller ones
- Remove duplicate logic
- Improve input validation

### 10) Personalized 4-week study plan template

Fill this in before you begin:
- Current level: `Beginner / Some basics / Intermediate`
- Daily study time: `___ minutes`
- Primary goal: `___`
